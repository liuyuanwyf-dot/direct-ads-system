# 直客广告系统 PRD 页面功能表

> 目标：将“模块 - 页面 - 目标 - 功能 - 状态”统一成一份可评审、可拆需求的 PRD 页面表。

## 1. 直客端 PRD

| 模块 | 页面 | 页面目标 | 核心功能 | 关键状态 |
| --- | --- | --- | --- | --- |
| 登录注册 | 登录页 | 完成账号进入 | 登录方式选择、验证码/密码登录、忘记密码入口 | 未登录、登录失败 |
| 登录注册 | 注册页 | 创建新账号 | 手机号/邮箱校验、验证码、设置密码、协议确认 | 注册中、注册成功 |
| 登录注册 | 忘记密码页 | 找回账号 | 身份验证、重置密码 | 验证中、重置成功 |
| 广告主认证 | 认证引导页 | 引导开始认证 | 材料说明、流程说明、开始认证 | 未开始、进行中 |
| 广告主认证 | 主体信息页 | 收集主体资料 | 账号归属、业务类型、品牌、主体信息 | 草稿、已填写 |
| 广告主认证 | 资质上传页 | 收集资质材料 | 营业执照、身份证明、授权书、补充材料 | 草稿、上传完成 |
| 广告主认证 | 提交确认页 | 提交审核 | 必填校验、信息预览、提交 | 待提交、已提交 |
| 广告主认证 | 认证结果页 | 查看审核结论 | 审核中、通过、补资料、驳回 | 审核中/通过/驳回 |
| 站点认证 | 站点列表页 | 管理站点 | 搜索、筛选、新建站点 | 待验证、已验证、验证不通过 |
| 站点认证 | 站点认证页 | 提交站点资质 | 域名、备案、截图、联系人 | 待验证、已验证、验证不通过 |
| 计划管理 | 计划列表页 | 管理计划 | 搜索、筛选、批量操作、创建 | 草稿、待审、通过（有效）、通过（受限）、驳回、投放中（正常）、投放中（预算受限）、暂停中（账户余额不足）、暂停中（总预算耗尽）、暂停中（人工暂停）、暂停中（计划到期）、已关闭、已归档 |
| 计划管理 | 新建计划页 | 创建投放计划 | 基本信息、预算、定向、站点、素材 | 草稿 |
| 计划管理 | 计划详情页 | 查看计划全貌 | 配置展示、审核状态、投放概览 | 待审、通过（有效）、通过（受限）、驳回、投放中（正常/预算受限）、暂停中（账户余额不足/总预算耗尽/人工暂停/计划到期）、已关闭、已归档 |
| 素材管理 | 素材列表页 | 管理素材资产 | 上传、筛选、状态查看 | 待审、通过、驳回 |
| 素材管理 | 素材上传页 | 新增素材 | 文件上传、文案填写、关联计划 | 上传中、待审 |
| 财务中心 | 充值页 | 完成充值 | 金额选择、支付方式、发票信息 | 待支付、支付成功 |
| 财务中心 | 充值记录页 | 查看流水 | 充值记录、状态、单号 | 成功、失败、处理中 |
| 消息中心 | 通知列表页 | 接收平台通知 | 审核结果、余额提醒、异常提醒 | 未读、已读 |

## 3. 优先级建议

### P0

- 登录注册
- 广告主认证
- 站点认证
- 计划创建
- 素材上传
- 运营端审核列表与详情

### P1

- 充值与充值记录
- 用户管理
- 投放池管理
- 素材管理

### P2

- 角色权限
- 审核规则
- 字典配置
- 操作日志
