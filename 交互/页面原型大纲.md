# 直客广告系统页面原型大纲

> 说明：这里不是视觉稿，而是每个页面应该怎么摆、有哪些区块、默认展示什么信息，方便后续画原型或切设计稿。

## 1. 直客端页面原型大纲

### 1.1 登录页

- 顶部品牌区
- 登录方式切换区
- 账号输入区
- 验证码/密码输入区
- 登录按钮
- 忘记密码、注册入口

### 1.2 注册页

- 品牌说明区
- 账号输入区
- 验证码区
- 密码设置区
- 协议勾选区
- 注册按钮

### 1.3 广告主认证页

- 流程进度条
- 账号归属选择区
- 业务类型区
- 品牌信息区
- 主体信息区
- 资质上传区
- 提交确认区
- 审核状态提示区

### 1.4 站点认证页

- 站点列表区
- 新建站点入口
- 站点基础信息区
- 备案与归属材料区
- 提交审核区
- 站点状态区

### 1.5 计划创建页

- 计划基础信息区
- 投放时间区
- 预算区
- 定向区
- 站点选择区
- 素材选择区
- 提交按钮区

### 1.6 素材上传页

- 素材类型切换区
- 文件上传区
- 文案编辑区
- 预览区
- 关联计划区
- 提交按钮区

### 1.7 充值页

- 当前余额区
- 充值金额区
- 支付方式区
- 发票信息区
- 提交支付区

### 1.8 通知列表页

- 通知分类筛选区
- 通知列表区
- 未读标识
- 跳转处理入口

## 2. 运营端页面原型大纲

### 2.1 工作台首页

- 数据概览卡片
- 待办列表
- 认证进度统计
- 充值与投放统计
- 风险提醒区

### 2.2 用户列表页

- 搜索条件区
- 用户表格区
- 操作按钮区
- 批量处理区

### 2.3 审核列表页

- 审核类型筛选区
- 状态筛选区
- 审核任务列表区
- 批量审核入口

### 2.4 审核详情页

- 申请信息区
- 资料预览区
- 规则命中区
- 审核操作区
- 审核历史区

### 2.5 投放池列表页

- 资源筛选区
- 资源表格区
- 标签区
- 上下架入口

### 2.6 充值记录页

- 筛选条件区
- 充值流水区
- 异常标记区
- 对账入口

### 2.7 素材管理页

- 素材筛选区
- 素材表格区
- 预览抽屉/弹窗
- 审核入口

## 3. 原型绘制顺序建议

1. 先画登录注册
2. 再画广告主认证、站点认证
3. 接着画计划创建、素材上传
4. 然后画运营端审核列表与详情
5. 最后补工作台、投放池、充值、系统配置
