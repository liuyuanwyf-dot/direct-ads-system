# 直客广告系统状态机整理

> 说明：以下整理覆盖 4 类核心状态机，分别是账号状态机、广告主认证审核状态机、站点认证状态机、计划审核状态机。  
> 写法采用「状态定义 + 流转表 + 说明」的方式，便于产品、研发、测试统一理解。

## 1. 账号状态机

### 1.1 状态定义

| 状态 | 中文名 | 说明 |
| --- | --- | --- |
| `pending_verify` | 待验证 | 用户已注册，但手机号/邮箱等验证未完成 |
| `active` | 正常 | 账号可正常登录和使用 |
| `frozen` | 冻结 | 因风控、异常或人工操作暂时不可用 |
| `disabled` | 禁用 | 由运营或管理员主动停用 |
| `closed` | 已注销 | 账号已关闭，不再允许登录 |

### 1.2 流转表

| 当前状态 | 触发动作 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| `pending_verify` | 完成手机号/邮箱验证 | `active` | 注册后完成验证进入可用状态 |
| `pending_verify` | 管理员作废 | `disabled` | 异常注册或违规注册可直接停用 |
| `active` | 风控冻结 | `frozen` | 命中风险规则、异常登录、异常充值等 |
| `active` | 管理员禁用 | `disabled` | 运营后台手动停用账号 |
| `active` | 用户主动注销 | `closed` | 用户申请注销账号 |
| `frozen` | 风控解除 | `active` | 风险解除后恢复使用 |
| `frozen` | 管理员禁用 | `disabled` | 冻结后进一步处置 |
| `disabled` | 管理员解禁 | `active` | 运营人工恢复账号 |
| `disabled` | 用户注销流程完成 | `closed` | 如果允许从禁用态完成注销，可进入已注销 |

### 1.3 业务说明

- 建议 `pending_verify` 仅在你们需要邮箱/手机号激活时启用。
- 如果产品不做激活环节，可以把 `pending_verify` 合并到 `active`，只保留 `active / frozen / disabled / closed`。
- `closed` 一般是终态，恢复账号需要重新注册或走特殊恢复流程。

## 2. 广告主认证审核状态机

### 2.1 状态定义

| 状态 | 中文名 | 说明 |
| --- | --- | --- |
| `draft` | 草稿 | 用户正在填写认证信息，尚未提交 |
| `submitted` | 已提交 | 用户已提交认证申请，等待进入审核 |
| `machine_reviewing` | 机审中 | 系统正在进行规则校验和风险识别 |
| `manual_reviewing` | 人审中 | 已进入人工审核队列 |
| `supplement_required` | 待补资料 | 资料不完整或需要补充说明 |
| `approved` | 审核通过 | 广告主认证成功 |
| `rejected` | 审核驳回 | 认证未通过，结束本次申请 |
| `withdrawn` | 已撤回 | 用户主动撤回未完成审核的申请 |

### 2.2 流转表

| 当前状态 | 触发动作 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| `draft` | 用户点击提交 | `submitted` | 从填写阶段进入申请阶段 |
| `submitted` | 系统拉取进入审核队列 | `machine_reviewing` | 进入自动校验 |
| `machine_reviewing` | 机审通过 | `manual_reviewing` | 机审通过后进入人审 |
| `machine_reviewing` | 机审失败且可补资料 | `supplement_required` | 缺项或材料不足 |
| `machine_reviewing` | 机审直接驳回 | `rejected` | 命中强规则或黑名单 |
| `manual_reviewing` | 人审通过 | `approved` | 最终审核通过 |
| `manual_reviewing` | 人审补资料 | `supplement_required` | 需补充材料后重新提交 |
| `manual_reviewing` | 人审驳回 | `rejected` | 最终不通过 |
| `supplement_required` | 用户补齐材料并重新提交 | `submitted` | 回到审核流程起点 |
| `supplement_required` | 用户撤回 | `withdrawn` | 放弃本次申请 |
| `draft` | 用户撤回草稿 | `withdrawn` | 草稿终止 |

### 2.3 业务说明

- 建议将机审和人审拆成两个子状态，便于运营看队列和处理效率。
- `supplement_required` 不建议视为失败终态，它是“可回流”的中间态。
- `approved` 和 `rejected` 可视为终态，但如果允许复审或重新发起，需要在业务上新建一笔申请，而不是强行回写旧单。

## 3. 站点认证状态机

### 3.1 状态定义

| 状态 | 中文名 | 说明 |
| --- | --- | --- |
| `pending_verify` | 待验证 | 站点已发起认证，但尚未完成验证 |
| `verified` | 已验证 | 站点认证通过，可正常使用 |
| `verification_failed` | 验证不通过 | 站点认证未通过 |

### 3.2 流转表

| 当前状态 | 触发动作 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| `pending_verify` | 用户提交验证材料 | `pending_verify` | 进入验证流程，状态保持不变，直到出结果 |
| `pending_verify` | 验证通过 | `verified` | 站点认证成功 |
| `pending_verify` | 验证不通过 | `verification_failed` | 站点认证失败 |
| `verified` | 撤销站点认证 | `verification_failed` | 站点失效后回到不通过态，或按业务需要保留历史记录 |

### 3.3 业务说明

- 站点认证状态仅保留 `待验证 / 已验证 / 验证不通过` 三态。
- 如果需要表达“审核中”，建议放在页面文案或申请详情里，不作为状态机状态。
- `verification_failed` 作为终态处理，不再定义“重新提交验证材料”的回流。

## 4. 计划审核状态机

### 4.1 状态定义

| 状态 | 中文名 | 说明 |
| --- | --- | --- |
| `draft` | 草稿 | 计划正在编辑，尚未提交 |
| `submitted` | 已提交 | 计划已提交，等待审核 |
| `reviewing` | 审核中 | 审核队列处理中 |
| `supplement_required` | 待修改 | 计划信息需调整后重新提交 |
| `approved_valid` | 审核通过（有效） | 计划可在任何场景中投放 |
| `approved_restricted` | 审核通过（受限） | 计划仅能在部分地区或特定场景投放 |
| `rejected` | 审核驳回 | 计划审核未通过 |
| `paused` | 已暂停 | 计划已上线后被暂停投放 |
| `ended` | 已结束 | 计划自然结束或手动结束 |

### 4.2 流转表

| 当前状态 | 触发动作 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| `draft` | 用户点击提交 | `submitted` | 进入审核流 |
| `submitted` | 系统进入审核队列 | `reviewing` | 开始审核 |
| `reviewing` | 审核通过且无限制 | `approved_valid` | 可在任何场景中投放 |
| `reviewing` | 审核通过但有限制 | `approved_restricted` | 仅在指定地区或场景中投放 |
| `reviewing` | 需要修改 | `supplement_required` | 计划参数、定向或素材需调整 |
| `reviewing` | 审核驳回 | `rejected` | 不通过 |
| `supplement_required` | 用户修改后重新提交 | `submitted` | 重新进入审核 |
| `approved_valid` | 到达投放开始时间 | `active` | 通过且无限制的计划进入投放 |
| `approved_restricted` | 到达可投放条件时 | `active` | 满足限制条件时才可投放 |
| `active` | 用户手动暂停 | `paused` | 投放暂停 |
| `paused` | 用户恢复投放 | `active` | 继续投放 |
| `active` | 到达结束时间 | `ended` | 计划结束 |
| `paused` | 到达结束时间 | `ended` | 即使暂停，也可自然结束 |

### 4.3 业务说明

- 如果你们计划表里已经有 `status` 和 `audit_status` 两套字段，建议：
  - `audit_status` 只管审核：`draft / submitted / reviewing / supplement_required / approved_valid / approved_restricted / rejected`
  - `status` 只管投放：`draft / active / paused / ended`
- 这样会更清晰，也更利于前后端分工。

- `approved_valid` 表示计划规则上允许在任何地区和场景投放。
- `approved_restricted` 表示计划审核通过，但在特定地区、年龄、人群或敏感场景下存在投放限制，例如电子烟不投美国、情趣用品不投 18 岁以下人群。

## 5. 推荐落库口径

| 对象 | 建议字段 | 说明 |
| --- | --- | --- |
| 账号 | `status` | 保存账号生命周期状态 |
| 广告主认证申请 | `audit_status` + `step_status` | `step_status` 管流程进度，`audit_status` 管审核结论 |
| 站点认证申请 | `audit_status` | 站点流程相对简单，可只保留审核状态 |
| 计划 | `status` + `audit_status` | 审核态与投放态分离 |

## 6. 计划投放状态机

### 6.1 状态定义

| 状态 | 中文名 | 说明 |
| --- | --- | --- |
| `delivery_running_normal` | 投放中（正常） | 计划正在正常投放，没有异常 |
| `delivery_running_budget_limited` | 投放中（预算受限） | 计划当日预算已消耗完，进入当日暂停，次日自动恢复 |
| `delivery_paused_balance_insufficient` | 暂停中（账户余额不足） | 直客账户余额小于等于 0，系统自动暂停所有广告 |
| `delivery_paused_budget_exhausted` | 暂停中（总预算耗尽） | 计划总预算消耗完，暂停投放，需重新设置总预算 |
| `delivery_paused_manual` | 暂停中（人工暂停） | 运营或直客手动暂停计划 |
| `delivery_paused_expired` | 暂停中（计划到期） | 计划投放时间到期，自动暂停 |
| `closed` | 已关闭 | 计划暂停后人工关闭，或暂停后一段时间无操作自动关闭；关闭后从资源池中移除 |
| `archived` | 已归档 | 计划已关闭后归档，后台管理页面默认不再展示 |

### 6.2 流转表

| 当前状态 | 触发动作 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| `approved_valid` | 满足投放条件并启动 | `delivery_running_normal` | 通过且无限制的计划进入正常投放 |
| `approved_restricted` | 满足限制条件并启动 | `delivery_running_normal` | 受限计划在满足投放条件后进入正常投放 |
| `delivery_running_normal` | 当日预算消耗完 | `delivery_running_budget_limited` | 当天暂停，次日自动恢复 |
| `delivery_running_normal` | 账户余额不足 | `delivery_paused_balance_insufficient` | 余额不足时自动暂停所有广告 |
| `delivery_running_normal` | 总预算耗尽 | `delivery_paused_budget_exhausted` | 计划整体暂停，等待重新设置总预算 |
| `delivery_running_normal` | 人工暂停 | `delivery_paused_manual` | 运营或直客主动暂停 |
| `delivery_running_normal` | 计划到期 | `delivery_paused_expired` | 到达投放时间上限后暂停 |
| `delivery_running_budget_limited` | 次日零点自动恢复且余额充足 | `delivery_running_normal` | 第二天恢复正常投放 |
| `delivery_running_budget_limited` | 次日零点自动恢复但余额不足 | `delivery_paused_balance_insufficient` | 恢复时仍受余额限制 |
| `delivery_paused_balance_insufficient` | 账户充值后余额恢复 | `delivery_running_normal` | 余额充足后恢复投放 |
| `delivery_paused_budget_exhausted` | 重新设置总预算并满足条件 | `delivery_running_normal` | 预算恢复后继续投放 |
| `delivery_paused_manual` | 人工恢复 | `delivery_running_normal` | 运营或直客重新开启计划 |
| `delivery_paused_expired` | 重新设置投放时间且满足条件 | `delivery_running_normal` | 重新排期后恢复投放 |
| `delivery_paused_manual` | 人工关闭计划 | `closed` | 关闭后不再参与投放 |
| `delivery_paused_balance_insufficient` | 长时间无操作自动关闭 | `closed` | 自动关闭规则由系统定时任务触发 |
| `delivery_paused_budget_exhausted` | 长时间无操作自动关闭 | `closed` | 自动关闭规则由系统定时任务触发 |
| `delivery_paused_expired` | 长时间无操作自动关闭 | `closed` | 自动关闭规则由系统定时任务触发 |
| `closed` | 手动归档 | `archived` | 归档后不在后台管理页面默认展示 |

### 6.3 业务说明

- `投放中` 有两个子状态：
  - `正常`：没有任何异常
  - `预算受限`：当日预算已用尽，第二天自动恢复
- `暂停中` 有四个子状态：
  - `账户余额不足`：账户余额小于等于 0，自动暂停所有广告
  - `总预算耗尽`：计划总预算用尽，需重新设置总预算
  - `人工暂停`：运营或直客手动暂停
  - `计划到期`：达到计划投放结束时间
- `已关闭` 表示计划已停止参与投放，并从资源池中移除。
- `归档` 表示计划已关闭后进入后台隐藏态，默认在管理页面不再展示。
- 如果你们后续希望更便于落库，可以把“投放中/暂停中”作为一级状态，把子状态写入 `delivery_sub_status`。
