# 直客广告系统数据字段表

> 说明：本文件把核心数据表的字段整理成字段字典格式，统一输出「字段名、中文名、说明、解释」，方便产品、研发和测试对齐。

## 1. 用户表 `user`

| 字段名 | 中文名 | 说明 | 解释 |
| --- | --- | --- | --- |
| `id` | 用户ID | 用户唯一标识 | 系统主键，用于关联其他业务表 |
| `account` | 登录账号 | 用户登录名 | 可为手机号、邮箱或自定义账号 |
| `password_hash` | 密码哈希 | 加密后的密码值 | 不存明文密码，只保存加密结果 |
| `mobile` | 手机号 | 用户绑定手机号 | 用于登录、通知、找回密码 |
| `email` | 邮箱 | 用户绑定邮箱 | 用于登录、通知、找回密码 |
| `status` | 账号状态 | 用户当前可用状态 | 如正常、禁用、冻结、注销 |
| `role_type` | 角色类型 | 用户所属角色 | 用于区分直客、运营、管理员等 |
| `created_at` | 创建时间 | 用户创建时间 | 记录账号首次创建的时间 |
| `updated_at` | 更新时间 | 用户信息更新时间 | 记录最近一次修改时间 |

## 19. 关联关系说明

| 关联关系 | 说明 | 解释 |
| --- | --- | --- |
| `user` -> `advertiser` | 用户对应广告主主体 | 一个用户可以有一个或多个主体，按业务规则控制 |
| `user` -> `site` | 用户对应站点 | 用户创建和管理站点资源 |
| `advertiser` -> `advertiser_auth_app` | 主体对应认证申请 | 每次认证申请都归属到主体 |
| `site` -> `site_auth_app` | 站点对应认证申请 | 站点认证记录与站点绑定 |
| `plan` -> `plan_material` | 计划关联素材 | 一个计划可以绑定多个素材 |
| `plan` -> `plan_delivery_pool` | 计划关联投放池 | 一个计划可选择多个投放资源 |
| `material` -> `plan_material` | 素材被计划引用 | 素材可复用到多个计划 |
| `user` -> `recharge_record` | 用户对应充值记录 | 保存每次充值交易流水 |
| `user` -> `message_notice` | 用户对应通知消息 | 所有消息按用户维度投递 |
