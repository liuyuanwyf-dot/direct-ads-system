# 直客广告系统业务模块与页面清单

> 目标：先把直客端与运营端的业务模块、所需页面、每个页面的核心功能梳理清楚，作为后续原型设计、菜单设计和开发拆分的基础。

## 1. 业务范围总览

### 1.1 直客端

- 登录注册模块
- 广告主认证流程
- 站点认证流程
- 计划创建与管理模块
- 素材模块
- 账户与充值模块
- 消息通知模块

### 1.2 运营端

- 工作台
- 用户管理
- 广告主认证审核
- 站点认证审核
- 计划审核
- 投放池管理
- 充值记录管理
- 素材管理
- 系统配置

## 2. 直客端页面清单

### 2.1 登录注册模块

| 页面 | 核心功能 |
| --- | --- |
| 登录页 | 手机号/邮箱登录、密码登录、验证码登录、记住账号、忘记密码入口 |
| 注册页 | 新账号注册、手机号/邮箱校验、验证码校验、设置密码、协议确认 |
| 忘记密码页 | 身份验证、重置密码、完成后回到登录页 |
| 账号绑定页 | 绑定手机号/邮箱、修改绑定信息、校验唯一性 |
| 协议页 | 用户协议、隐私政策、平台规则展示 |

### 2.2 广告主认证流程

| 页面 | 核心功能 |
| --- | --- |
| 认证引导页 | 展示认证流程、材料清单、认证收益说明、开始认证入口 |
| 账号归属选择页 | 选择公司主体/授权主体/个人主体（如个人类型不开放可隐藏） |
| 业务类型选择页 | 选择行业、业务类型、投放场景 |
| 品牌信息页 | 填写品牌名称、品牌与主体关系、品牌备注 |
| 主体信息页 | 公司名称、地址、联系人、法人信息、授权人信息 |
| 资质上传页 | 营业执照、身份证明、持证照片、授权书、联系方式、补充材料上传 |
| 提交确认页 | 必填项校验、信息预览、提交审核、返回修改 |
| 认证结果页 | 查看审核中/通过/补资料/未通过状态、查看原因、再次提交 |
| 认证详情页 | 查看历史提交记录、审核意见、材料版本、操作日志 |

### 2.3 站点认证流程

| 页面 | 核心功能 |
| --- | --- |
| 站点列表页 | 站点搜索、筛选、状态查看、新建站点入口 |
| 新建站点页 | 填写站点名称、域名、URL、行业分类、站点描述 |
| 站点认证页 | 提交备案/ICP/站点归属材料、站点截图、联系人信息 |
| 站点详情页 | 展示站点基本信息、认证状态、历史审核结果 |
| 站点结果页 | 待验证、已验证、验证不通过 |
| 站点编辑页 | 修改站点信息、补充材料、重新发起审核 |

### 2.4 计划创建与管理模块

| 页面 | 核心功能 |
| --- | --- |
| 计划列表页 | 计划搜索、筛选、状态查看、批量操作、创建入口；状态包含草稿、待审、通过（有效）、通过（受限）、驳回、投放中（正常）、投放中（预算受限）、暂停中（账户余额不足）、暂停中（总预算耗尽）、暂停中（人工暂停）、暂停中（计划到期）、已关闭、已归档；归档计划默认隐藏 |
| 新建计划页 | 基本信息、投放周期、预算、出价方式、定向条件、关联站点、关联素材 |
| 计划详情页 | 展示计划配置、审核状态、投放概览、消耗数据；投放状态包含投放中（正常/预算受限）、暂停中（账户余额不足/总预算耗尽/人工暂停/计划到期）、已关闭、已归档 |
| 计划编辑页 | 修改预算/定向/素材/投放时间、保存草稿、重新提交 |
| 计划审核结果页 | 查看通过（有效）/通过（受限）/驳回/待修改原因 |
| 计划复制页 | 复制已有计划并快速生成新计划 |

> 注：如果你们内部“光里模块”是指投放管理、计划管理或流量管理，这一块可直接替换页面命名。

### 2.5 素材模块

| 页面 | 核心功能 |
| --- | --- |
| 素材列表页 | 图片/视频/文案分类、搜索筛选、状态筛选、批量操作 |
| 素材上传页 | 上传图片、视频、文案内容、填写名称、关联计划 |
| 素材详情页 | 素材预览、审核状态、关联计划、审核意见 |
| 素材编辑页 | 修改素材信息、替换文件、重新提交审核 |
| 素材审核结果页 | 通过、待补充、驳回 |

### 2.6 账户与充值模块

| 页面 | 核心功能 |
| --- | --- |
| 账户概览页 | 余额、冻结金额、消耗、充值入口、预警信息 |
| 充值页 | 选择充值金额、支付方式、发票信息、提交支付 |
| 充值记录页 | 查询充值流水、状态、时间、金额、支付单号 |
| 充值详情页 | 查看支付详情、到账状态、异常原因 |

### 2.7 消息通知模块

| 页面 | 核心功能 |
| --- | --- |
| 通知列表页 | 展示审核结果、余额提醒、计划异常、系统公告 |
| 通知详情页 | 查看通知内容、处理建议、跳转对应业务页面 |

## 4. 建议的首版优先级

### 4.1 第一阶段，先跑通主链路

- 登录注册
- 广告主认证
- 站点认证
- 计划创建
- 素材上传
- 运营端审核列表和审核详情

### 4.2 第二阶段，补齐运营能力

- 用户管理
- 投放池管理
- 充值记录
- 素材管理
- 审核日志

### 4.3 第三阶段，增强管理能力

- 角色权限
- 规则配置
- 操作日志
- 数据看板

## 5. 结论

这套页面结构可以支持以下完整闭环：

1. 直客注册并完成主体认证
2. 创建站点并提交站点认证
3. 创建计划并上传素材
4. 运营端完成机审、人审和结果流转
5. 计划进入投放池并开始投放
6. 充值和素材管理形成配套运营能力
