# 直客广告系统菜单路由结构

> 说明：以下结构按「直客端」和「运营端」两套后台来拆分，优先保证主链路清晰可落地。页面命名可按你们的品牌规范再微调。

## 1. 直客端路由

```text
/login                      登录
/register                   注册
/forgot-password            忘记密码
/bind-account               账号绑定
/agreement                  协议中心

/customer
  /dashboard                账户概览
  /auth
    /advertiser             广告主认证
      /guide                 认证引导
      /profile               账号归属与主体信息
      /upload                资质上传
      /submit                提交确认
      /result                认证结果
      /detail                认证详情
    /site                    站点认证
      /list                  站点列表
      /create                新建站点
      /edit/:id              编辑站点
      /detail/:id            站点详情
      /submit/:id            站点提交认证
      /result/:id            站点认证结果
  /plan
    /list                    计划列表
    /create                  新建计划
    /edit/:id                编辑计划
    /detail/:id              计划详情
    /copy/:id                复制计划
    /review/:id              计划审核结果
  /material
    /list                    素材列表
    /upload                  素材上传
    /edit/:id                素材编辑
    /detail/:id              素材详情
    /review/:id              素材审核结果
  /finance
    /recharge                充值
    /recharge-record         充值记录
    /recharge-detail/:id     充值详情
  /message
    /list                    通知列表
    /detail/:id              通知详情
```

## 2. 运营端路由

```text
/admin
  /dashboard                工作台
  /todo                     待办中心
  /user
    /list                    用户列表
    /detail/:id              用户详情
    /edit/:id                用户编辑
  /audit
    /advertiser
      /machine               广告主机审列表
      /manual                广告主人审列表
      /detail/:id            广告主审核详情
      /log/:id               广告主审核日志
    /site
      /list                  站点审核列表
      /detail/:id            站点审核详情
    /plan
      /list                  计划审核列表
      /detail/:id            计划审核详情
    /material
      /list                  素材审核列表
      /detail/:id            素材审核详情
  /pool
    /list                    投放池列表
    /detail/:id              投放池详情
    /config/:id              投放池配置
  /finance
    /recharge-record         充值记录
    /recharge-detail/:id     充值详情
    /exception/:id           异常处理
  /material
    /list                    素材管理列表
    /detail/:id              素材管理详情
    /library                 素材库管理
  /system
    /role                    角色权限
    /audit-rule              审核规则配置
    /dictionary              字典配置
    /log                     操作日志
```

## 3. 菜单结构建议

### 3.1 直客端一级菜单

- 账户概览
- 广告主认证
- 站点认证
- 计划管理
- 素材管理
- 财务中心
- 消息中心

### 3.2 运营端一级菜单

- 工作台
- 用户管理
- 审核中心
- 投放池管理
- 财务管理
- 素材管理
- 系统配置
